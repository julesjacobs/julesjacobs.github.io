1679

Leibniz’s Calculus Ratiocinator

Leibniz imagined a universal logical calculus where disputes could be resolved through computation—Calculemus! His binary arithmetic presaged machine logic.

1843

Ada Lovelace’s Note G

Lovelace outlined procedures for Babbage’s Analytical Engine, distinguishing data from operations—the conceptual ancestor of separating syntax and semantics.

1847

George Boole’s Algebra of Logic

Boole’s symbolic laws introduced algebraic manipulation of propositions. Modern compilers still reason about predicates using similar identities.

1879

Invention of the Light Bulb

Electric light extended the laboratory day and fueled industrial research cultures that soon birthed formal methods labs and computing pioneers.

1879

Frege’s Begriffsschrift

Frege’s ideography introduced quantifiers and variable binding akin to \( \forall x.\,P(x) \). His structural rules foreshadow modern proof calculi.

1893

Peano Axiomatizes Arithmetic

Peano’s formal axioms distilled induction as a logical operator, a principle mirrored in recursive type definitions and proof assistants.

1931

Gödel’s Incompleteness Theorems

By encoding proofs as numbers, Gödel exposed intrinsic program-like self-reference. His results delineate the boundaries of static analysis and formal verification.

1936

Church’s λ-Calculus

Church defined computation as β-reduction, crystallized by expressions like \( (\lambda x.\,x)\;y \). Functional programming still mirrors these reductions.

1936

Turing Machines

Turing’s abstract machines framed computability and complexity, giving us the halting problem and the blueprint for stored-program computers.

1947

The Point-Contact Transistor

Transistors translated logical abstractions into scalable hardware, making the implementation layer of PL semantics physically realizable.

1957

Fortran & Compilers

IBM’s Fortran compiler automated optimization, inspiring decades of work on control-flow graphs and program analysis.

1958

Lisp & Symbolic Computation

McCarthy’s Lisp treated code as data, realizing homoiconicity and a meta-circular evaluator that maps naturally onto \( \lambda \)-terms.

1969

Curry–Howard Correspondence

Proofs-as-programs equated \( \Gamma \vdash t : A \) with \( \Gamma \vdash A \) provable, aligning logic with type theory and guiding the design of rich type systems.

1969

ARPANET’s First Link

Networked computation set the stage for distributed semantics, remote theorem proving, and collaborative language tooling.

1978

ML & Hindley–Milner Types

Milner’s type inference produced principal types \( \forall \alpha.\,\alpha \to \alpha \), balancing expressiveness with decidable checking.

1980

Smalltalk-80

The Xerox PARC team realized pervasive objects, message passing, and live environments—informing modern IDEs and PL tooling.

1984

Coq Interactive Theorem Prover

Built on the Calculus of Inductive Constructions, Coq turned dependent types into a practical medium for machine-checked proofs and program extraction.

1990

The Haskell Report

The Haskell committee unified lazy evaluation with type classes, formalized by laws such as \( \mathsf{Monad} \) associativity, and demonstrated industrial-strength pure FP.

1995

Java & the Virtual Machine

Java’s bytecode VM standardized portability and influenced verification-friendly intermediate representations such as LLVM IR.

2012

Homotopy Type Theory

HoTT enriched type theory with higher inductive types and univalence \( a \simeq b \Rightarrow a = b \), expanding the expressive frontier of constructive logic.

2015

Rust 1.0

Rust’s borrow checker operationalizes affine logic to deliver memory safety without garbage collection, a live demonstration of types as lightweight proofs.

2021

Lean 4

Lean 4 blends a programmable tactic language with a performant compiler, turning dependent type theory into a practical environment for research and PL pedagogy.
