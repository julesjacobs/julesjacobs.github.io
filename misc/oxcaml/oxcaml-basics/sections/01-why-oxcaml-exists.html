Why OxCaml exists

OxCaml starts from OCaml's safe, high-level programming model and adds explicit, compiler-checked control over low-level behavior needed for high-performance code: parallelism, allocation, and representation.

Parallelism

Parallel programs need to use multiple cores without introducing bugs. OxCaml's type checker tracks which functions can be safely called in parallel, and when use of mutable state is safe.

Allocation

A GC pause at the wrong time is unacceptable in low-latency code. OxCaml adds stack allocation, with type checking to ensure stack-allocated values do not escape.

Representation

High-performance programs need cache locality, fewer pointer indirections, and fewer heap allocations. OxCaml uses types and layouts to give control over value representation.

OxCaml language features

In this course you'll learn about the following OxCaml features.

  • Modesx @ local, f @ portable, t @ contended — how values and functions may be used.
  • Stack allocationstack_ expr, exclave_ expr — allocate temporary values without putting them on the heap.
  • Zero allocation checkslet[@zero_alloc] f ... — ask the compiler to check that a function does not allocate on normal paths.
  • Layouts and unboxed valuesfloat#, #(x, y), #{ x : float# } — control value representation.
  • Kindstype t : value mod portable, ('a : value & immediate) — track type-level layout and mode information.
  • Templateslet%template, [@mode], [@kind] — generate related definitions across modes, kinds, and layouts.

Learning goals

By the end of the course, you should be able to:

  • read small OxCaml examples that use parallelism, stack allocation, zero-allocation checks, and representation layouts;
  • recognize common annotations such as @ local, @ contended, @ portable, layout annotations, and [@zero_alloc] in real signatures;
  • explain common compiler errors involving escaping values, unsafe mutable access, heap allocation, or representation mismatch;
  • choose the relevant OxCaml feature for small performance-sensitive examples.
