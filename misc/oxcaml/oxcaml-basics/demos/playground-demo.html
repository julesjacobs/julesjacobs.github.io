OxCaml Basics Playground Demo

This is an ordinary HTML course page with embedded OxCaml examples. Each runnable block is written as an <oxcaml> tag; the script at the end of the page turns those tags into editors.

Types and Values

In toplevel mode, each phrase ending in ;; reports the inferred type and value. This is useful for short conceptual examples.

let language = "OxCaml";; let answer = 40 + 2;; let describe name n = Printf.sprintf "%s example: %d" name n;; describe language answer;;

Locality and Stack Allocation

OxCaml can track local values. This example allocates a pair on the stack, consumes it locally, and prints the result.

let sum () = let local_ pair : int * int = stack_ (20, 22) in let x, y = pair in x + y;; print_endline (string_of_int (sum ()));;

Local Arguments

Mode annotations can appear on function parameters. Here, the parameter is local to the function body.

let bump (local_ x : int) = x + 1;; print_endline (string_of_int (bump 41));;

Errors as Teaching Material

The embedded playground also works for exercises where the initial code is intentionally wrong. This one returns a stack-allocated value without marking the return as local.

let f () = stack_ (3, 5)
