OOPSLA 2026 · Probabilistic programming

Type-Directed Discretization of Probabilistic Programs

Katherine Wu, Jules Jacobs, Kevin Batz, Alexandra Silva. When a program only ever compares its real-valued samples against constants, only finitely many intervals matter. Slice infers those intervals with a type system and turns the program into a discrete one that fast exact-inference engines can solve. The talk, slide by slide

    The paper

    Katherine Wu (Cornell University), Jules Jacobs (ETH Zurich; Jane Street), Kevin Batz (University of Münster), Alexandra Silva (Cornell University). Type-Directed Discretization of Probabilistic Programs. OOPSLA 2026.

    In one sentence

    Types carry the cuts: every real-valued type records the thresholds its values will be compared against, type inference finds them across closures, data structures and recursion, and the types direct a source-to-source discretization whose Boolean query probabilities equal the original's.
