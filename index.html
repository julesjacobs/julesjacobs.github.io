Research projects

Safe and verified systems programming

OxCaml is Jane Street's extension of OCaml for safe, fast systems programming. Its modes track whether a value can escape its stack frame or be shared between threads, and mode crossing lets integers, immutable data and other suitable types skip those restrictions automatically. Vox builds on OxCaml to check specifications at compile time, with refinement types and ghost proofs that are erased before code generation. As AI agents write more of our code, such specifications let people stay in charge of what that code does.

Network verification

KATch checks network configurations for properties such as reachability and isolation, typically in well under a second. StacKAT extends this to unbounded state such as MPLS label stacks, and SER decides whether stateful networked programs are serializable. NEST compiles session-type protocols into monitors that run on programmable switches. These tools rest on fast automata algorithms; Boa, for example, minimizes deterministic, weighted and probabilistic automata with one generic algorithm.

Deadlock freedom and verified concurrency

Programs that communicate over channels or share locks can deadlock. We design type systems and separation logics in which well-typed or verified programs never deadlock, and later work also verifies that programs follow their protocols and compute the right results. All proofs are mechanized in Coq/Rocq using Iris.

Probabilistic programming

When continuous random values only matter through comparisons with constants, Slice rewrites a probabilistic program into a discrete one, so that exact solvers can compute its distribution. In Paradoxes of Probabilistic Programming, I showed how infinitesimal probabilities resolve the paradoxes that arise when a program conditions on an event of probability zero.

PapersSlice (OOPSLA'26), Paradoxes (POPL'21)

Other software. Eggstract extracts shared, acyclic DAGs from e-graphs, with a Rust library, a command-line tool and an optional CP-SAT backend.

Some of this work has found its way into industry:

  • Jane Street. I work with Jane Street on OxCaml. Mode crossing is implemented in the OxCaml compiler and deployed in Jane Street's code base, and Vox builds compile-time verification on top of OxCaml.
  • Google. Google's open-source NetKAT implementation builds its packet sets and transformers on our verifier KATch.

If your company has software or infrastructure where stronger guarantees would help, I'd be glad to talk about working together, for example on a joint project or by hosting one of my students as an intern. Email me.
