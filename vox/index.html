Vox

Refinement types, ghost code and ownership for OxCaml

Code on GitHub Talk

What it is

Vox is a fork of the OxCaml compiler that checks specifications at compile time. A type can carry a refinement, such as {r : int | lo <= r && r <= hi}, and the compiler turns each function's refinements into verification conditions that an SMT solver must prove. Proofs are written as ghost code, which the compiler checks and then erases before code generation. OxCaml's uniqueness modes make ghost ownership tokens affine, and these tokens are how Vox specifies mutable state such as cells, hash tables and communication between domains.

Specifications let people check what a program does by reading its specifications instead of every line of its implementation. That matters more as more code is written by AI agents.

An example

let (clamp @ total) (lo : int) (hi : {h : int | lo <= h}) (x : int) :
    {r : int | lo <= r && r <= hi} =
  if x < lo then lo else if x > hi then hi else x

let bounded (x : int) : {r : int | 0 <= r && r <= 10} =
  clamp 0 10 x

The caller must pass ordered bounds, and the function guarantees a result within them. The solver proves both from the code; nothing is checked at run time, and the client calls clamp as usual. From bounded_clamp.ml.

Verified programs

Larger examples in the repository, with what is proved about each:

  • Flat hash table. A mutable hash table proved to behave as a finite map.
  • CDCL SAT solver. Terminates on every formula within its size limits; Sat comes with a satisfying assignment, and Unsat means none exists.
  • Hindley–Milner type inference. Sound and principal with respect to a declarative typing relation.
  • Compiler from a small ML to WebAssembly. Emits valid bytes, runs safely and agrees with the source semantics.
  • LZ4 block compression. Compressor and decoder equal to a specification, with a round-trip theorem.
  • Textbook RSA. Modular exponentiation on unbounded integers and the RSA round trip.
  • Online union–find. Implements a pure partition model, with amortized cost bounds.
  • Myers diff. Produces an edit script with the minimum number of insertions and deletions.
  • E-graphs. Equalities come with a derivation from the caller's rewrite rules.
  • One-shot channels. A receiver in another domain takes the payload only after the sender has put it there.

Try it

  1. Check out the vox branch and configure it with a local install prefix, as described in the README.
  2. Install Z3 and put it on your PATH.
  3. Run ./dev init, then ./dev test vox/bounded_clamp.ml.

The tour of the tests walks through the examples, and Verification programming explains how to write contracts and reusable proofs. When the solver rejects a goal, compile with -dvc to see the goal, its assumptions and the solver's model.

Related

Vox builds on OxCaml's modes; our paper Mode Crossing (ICFP'26) is about how values of suitable types move between modes. Vox is research software under active development.
