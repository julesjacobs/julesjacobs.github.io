Kleene Algebra with Stacks Is Complete

Jules Jacobs. Manuscript, November 2026.

paper .pdf paper with Lean statements .pdf Lean sources .zip

Abstract

A regular expression can be read as a nondeterministic program that consumes a prefix of a word. We consider programs that can also push letters onto the front, treating the word as a stack. We write pa for pushing the letter a and qa for popping it. We prove that three elementary stack laws, paqa = 1, paqb = 0 for a ≠ b, and qapa ≤ 1, together with ordinary Kleene algebra, completely axiomatize equivalence of these programs as relations on finite stacks over any alphabet. This refutes the conjecture of the StacKAT paper that these laws do not suffice. We give a new decision procedure for inclusion between two such programs and turn its positive answers into derivations by star induction. We extend completeness to programs that also test and assign finitely many variables with finite domains, formalize both completeness theorems in Lean, and verify an executable version of the procedure, which returns a counterexample when inclusion fails.

The specification

The statement of the main theorem depends only on this file. It defines the expressions, their meaning as relations on stacks, and the derivation rules, and it uses only the Lean core library. 

-- The trusted specification: syntax, semantics, derivations, and Theorem 1. Lean core only.
namespace Stackat

/-- Expressions over a stack alphabet `A`. -/
inductive Expr (A : Type) where
  | zero | one | push (a : A) | pop (a : A)
  | add (e f : Expr A) | mul (e f : Expr A) | star (e : Expr A)

-- Notation: 0, 1, e + f, e * f and e⋆ stand for zero, one, add, mul and star.
instance : Zero (Expr A) := ⟨.zero⟩
instance : One (Expr A) := ⟨.one⟩
instance : Add (Expr A) := ⟨.add⟩
instance : Mul (Expr A) := ⟨.mul⟩
scoped postfix:max "⋆" => Stackat.Expr.star

/-- `Steps r s t`: `t` is reached from `s` by zero or more `r`-steps. -/
inductive Steps (r : α → α → Prop) : α → α → Prop
  | refl : Steps r s s
  | step : r s m → Steps r m t → Steps r s t

/-- The relation `R e` between input and output stacks, written top first. -/
def R : Expr A → List A → List A → Prop
  | 0 => fun _ _ => False
  | 1 => Eq
  | .push a => fun s t => t = a :: s
  | .pop a => fun s t => s = a :: t
  | e + f => fun s t => R e s t ∨ R f s t
  | e * f => fun s t => ∃ m, R e s m ∧ R f m t        -- `e` runs first
  | e⋆ => Steps (R e)

set_option hygiene false
scoped notation:25 "⊢ " e:51 " ≈ " f:51 => Stackat.Derives e f        -- `e = f` is derivable
scoped notation:25 "⊢ " e:51 " ≤ " f:51 => Stackat.Derives (e + f) f  -- `e ≤ f` is `e + f = f`

/-- Derivability from the Kleene algebra laws and exactly the three stack laws. -/
inductive Derives {A : Type} : Expr A → Expr A → Prop where
  | refl : ⊢ e ≈ e                                         -- equational reasoning
  | symm : ⊢ e ≈ f → ⊢ f ≈ e
  | trans : ⊢ e ≈ f → ⊢ f ≈ g → ⊢ e ≈ g
  | add_congr : ⊢ e ≈ e' → ⊢ f ≈ f' → ⊢ e + f ≈ e' + f'
  | mul_congr : ⊢ e ≈ e' → ⊢ f ≈ f' → ⊢ e * f ≈ e' * f'
  | star_congr : ⊢ e ≈ f → ⊢ e⋆ ≈ f⋆
  | add_assoc : ⊢ (e + f) + g ≈ e + (f + g)                -- idempotent semiring
  | add_comm : ⊢ e + f ≈ f + e
  | add_zero : ⊢ e + 0 ≈ e
  | add_idem : ⊢ e + e ≈ e
  | mul_assoc : ⊢ (e * f) * g ≈ e * (f * g)
  | one_mul : ⊢ 1 * e ≈ e
  | mul_one : ⊢ e * 1 ≈ e
  | zero_mul : ⊢ 0 * e ≈ 0
  | mul_zero : ⊢ e * 0 ≈ 0
  | mul_add : ⊢ e * (f + g) ≈ e * f + e * g
  | add_mul : ⊢ (e + f) * g ≈ e * g + f * g
  | star_unfold_left : ⊢ 1 + e * e⋆ ≈ e⋆                   -- Kleene star
  | star_unfold_right : ⊢ 1 + e⋆ * e ≈ e⋆
  | star_induct_left : ⊢ e * f ≤ f → ⊢ e⋆ * f ≤ f
  | star_induct_right : ⊢ f * e ≤ f → ⊢ f * e⋆ ≤ f
  | push_pop : ⊢ .push a * .pop a ≈ 1                      -- the three stack laws
  | push_pop_ne : a ≠ b → ⊢ .push a * .pop b ≈ 0
  | pop_push : ⊢ .pop a * .push a ≤ 1

/-- **Theorem 1**, for every alphabet: `R e ⊆ R f` iff `⊢ e ≤ f`. -/
def SoundnessAndCompleteness : Prop :=
  ∀ (A : Type) (e f : Expr A), (∀ s t, R e s t → R f s t) ↔ ⊢ e ≤ f

end Stackat
